# 检测规则参考文档

## 规则设计原则

本 Skill 采用**规则引擎 + 正则匹配**的方式检测敏感信息，MVP 阶段不依赖大模型推理，确保：
- **确定性** — 相同输入始终产生相同输出
- **高性能** — 100 个文本文件 30 秒内完成
- **零依赖** — 纯 Python 标准库实现

## 检测类别

### 1. 个人敏感信息

| 检测类型 | 风险等级 | 检测方式 | 示例 |
|---------|---------|---------|------|
| 手机号 | 中 | 正则 | `13812345678` |
| 身份证号 | 高 | 正则 + 校验 | `32010619990101001X` |
| 银行卡号 | 高 | 正则 | `6222021234567890` |
| 邮箱 | 低 | 正则 | `test@example.com` |
| 固定电话 | 低 | 正则 | `025-88888888` |
| 护照号 | 高 | 正则 | `E12345678` |

### 2. 企业敏感信息

| 检测类型 | 风险等级 | 检测方式 | 示例 |
|---------|---------|---------|------|
| 统一社会信用代码 | 中 | 正则 | `91320100MA1XXXXXXX` |
| 合同金额 | 中 | 关键词 + 金额规则 | `合同金额：280000 元` |
| 项目编号 | 中 | 关键词 | `项目编号：EDU-001` |

### 3. 开发者密钥（高风险）

| 检测类型 | 风险等级 | 检测方式 | 示例 |
|---------|---------|---------|------|
| API Key | 高 | 关键词 + 正则 | `API_KEY=sk-test-xxx` |
| AccessKey | 高 | 关键词 + 正则 | `ACCESS_KEY=AKIAxxx` |
| SecretKey | 高 | 关键词 | `SECRET_KEY=xxx` |
| Token | 高 | 关键词 + 正则 | `Authorization: Bearer xxx` |
| Password | 高 | 关键词 | `PASSWORD=xxx` |
| 数据库连接串 | 高 | URL 模式 | `mysql://user:pass@host/db` |
| SSH 私钥 | 高 | 私钥头部检测 | `BEGIN OPENSSH PRIVATE KEY` |
| JWT | 高 | 正则 | `eyJhbGciOi...` |
| 服务器 IP | 中 | 正则 | `192.168.1.1` |

### 4. 文件风险特征

| 检测类型 | 风险等级 | 说明 |
|---------|---------|------|
| `.env` 文件 | 高 | 环境变量配置文件 |
| `secrets.json` | 高 | 密钥配置文件 |
| `private_key.pem` | 高 | 私钥文件 |
| `id_rsa` | 高 | SSH 私钥文件 |
| 密码相关配置 | 高 | 包含 password/key/secret 的配置行 |

## 风险分级规则

### 高风险判定
符合以下任一条件：
- API Key / SecretKey / AccessKey / Token
- 数据库连接串 / SSH 私钥 / JWT
- 身份证号 / 银行卡号
- `.env` 文件中的密码字段
- 生产环境配置文件中的密钥

### 中风险判定
符合以下任一条件：
- 手机号 / 合同金额 / 客户名称
- 项目编号 / 联系人信息 / 服务器 IP
- 预算金额 / 内部项目代号
- 统一社会信用代码

### 低风险判定
符合以下任一条件：
- 普通邮箱 / 姓名
- 固定电话 / 公开公司名称
