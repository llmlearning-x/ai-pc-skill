# 模型内存估算参考

## 每参数字节数

| 精度 | 字节/参数 | 说明 |
| --- | ---: | --- |
| FP32 | 4 | 全精度，本地部署一般不用 |
| FP16 / BF16 | 2 | 半精度，质量损失小 |
| INT8 | 1 | 8bit 量化 |
| INT4 | 0.5 | 4bit 量化，本地 LLM 主流 |

## 估算规则

```
权重大小 ≈ 参数量 × 每参数字节数
总需求   ≈ 权重大小 × 运行时开销系数（默认 1.5）
```

例如 7B INT4：权重 ≈ 7 × 0.5 = 3.5 GB，总需求 ≈ 3.5 × 1.5 ≈ 5.3 GB。

## 运行时开销系数（1.5）的依据

实际部署在权重之外还需要：

- **KV Cache**：随 context length 增长，7B 模型 4K 上下文约 0.5~1 GB（视层数与精度）
- **运行时缓冲**：推理框架的中间激活、临时 buffer
- **Tokenizer / 框架开销**：tokenizer 词表、运行时本身占用
- **操作系统余量**：需为 OS 与其他程序保留内存

1.5 是覆盖 KV cache（4K~8K 上下文）+ 运行时缓冲的经验系数；长上下文场景应进一步提高。

> 禁止将模型权重大小直接等同为运行内存。

## 推荐等级

| 等级 | 含义（总需求占可用 RAM 比例） |
| --- | --- |
| EXCELLENT | ≤ 30% |
| RECOMMENDED | ≤ 50% |
| LIMITED | ≤ 80% |
| NOT_RECOMMENDED | > 80% |

所有估算结果标记 **ESTIMATED**，实际性能以 Benchmark 实测（BENCHMARKED）为准。

## 模型推荐规则（V0.2，advisor 实现与之同步）

推荐清单覆盖 Qwen2.5 0.5B / 1.5B / 3B / 7B INT4：

1. **等级**：按 `总需求 = 参数量 × 0.5B × 1.5` 对照可用 RAM，用上表阈值分级。
2. **设备选择**（只推荐实测通过 smoke test 的设备）：
   - GPU 实测通过 → 优先 GPU（LLM/大吞吐）；
   - ≤1.5B 且 NPU 实测通过 → 可用 NPU（低功耗轻量）；
   - 否则 CPU 兜底（兼容性）。
3. **标注**：full 模式 GenAI Benchmark 实测通过的模型标 **BENCHMARKED**，其余标 **ESTIMATED**。
4. 星级展示：EXCELLENT=★★★★★ / RECOMMENDED=★★★★ / LIMITED=★★★ / NOT_RECOMMENDED=不建议。
