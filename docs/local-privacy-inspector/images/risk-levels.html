风险分级规则
根据敏感信息类型自动判定风险等级
🔴
高风险
• API Key / SecretKey / AccessKey
• Token / JWT / 数据库连接串
• SSH 私钥 / 云厂商密钥
• 身份证号 / 银行卡号
• .env 文件中的密码字段
🟡
中风险
• 手机号 / 合同金额 / 客户名称
• 项目编号 / 联系人信息
• 服务器 IP / 预算金额
• 内部项目代号
• 统一社会信用代码
🟢
低风险
• 普通邮箱 / 姓名
• 固定电话
• 公开公司名称
• 非完整地址
🔵
提示信息
• 文件名包含 confidential
• 文件名包含 internal / draft
• 文件名包含 backup / final
