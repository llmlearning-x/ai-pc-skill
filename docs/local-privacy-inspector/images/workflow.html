隐私检查工作流程
1
用户输入
指定单个文件路径（txt / md / docx / pdf / xlsx 等）
2
文本提取（extractor）
根据文件类型解析并提取纯文本内容
3
敏感检测（detector）
正则规则引擎识别 18+ 种敏感信息类型
4
脱敏处理（masker）
对所有命中结果进行默认脱敏，避免二次泄露
5
风险分级（classifier）
按高/中/低/提示四级分类，生成处理建议
6
报告输出（reporter）
生成 Markdown / JSON 格式的本地隐私检查报告
📄 报告包含
• 扫描概览（文件信息、风险等级、发现数量）
• 风险统计（高/中/低分级数量）
• 敏感信息详情（脱敏展示 + 行号 + 上下文 + 建议）
• 安全声明（本地完成、未上传、未修改原文件）
